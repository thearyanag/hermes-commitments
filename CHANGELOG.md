# Changelog

## 0.2.0 — Unreleased

Initial public package preparation; development status.

- Quiet, model-driven commitment capture, progress, completion, and follow-up
  decisions through Hermes's configured auxiliary model and existing auth.
- Durable SQLite state, attributed history, owner controls, lifecycle handling,
  and explicit quiet-hour/frequency preferences.
- Shared state across verified owner-private conversations in a profile.
- Hidden local follow-up inputs through a Desktop SDK component in the same
  package. Natural assistant replies remain visible.
- Fenced worker/dispatch claims and conservative handling of uncertain delivery.

Full group/room support, group-to-DM reconciliation, messaging transport
qualification, cold/busy/restart delivery qualification, and broader semantic
evaluation remain unfinished. See [validation](docs/VALIDATION.md).
